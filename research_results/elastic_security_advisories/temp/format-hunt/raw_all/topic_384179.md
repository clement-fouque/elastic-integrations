**Packetbeat Out-of-bounds Read (ESA-2025-31)** 

Out-of-bounds read (CWE-125) allows an unauthenticated remote attacker to perform a buffer overflow (CAPEC-100) via the NFS protocol dissector, leading to a denial-of-service (DoS) through a reliable process crash when handling truncated XDR-encoded RPC messages.

**Affected Versions:**

* 7.x: All versions   
* 8.x: All versions from 8.0.0 up to and including 8.19.8  
* 9.x:   
  * All versions from 9.0.0 up to and including 9.1.8  
  * All versions from 9.2.0 up to and including 9.2.2

**Solutions and Mitigations:**

The issue is resolved in version 8.19.9, 9.1.9, and 9.2.3.
