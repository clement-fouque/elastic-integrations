**Elastic Products are not affected by this issue.**

On Oct 25, 2022, Elastic became aware of the [Forthcoming OpenSSL 3.0.7 Release announcement](https://mta.openssl.org/pipermail/openssl-announce/2022-October/000238.html), which was made available on Nov 1, 2022. The security issues addressed in this release do not affect OpenSSL versions before 3.0.

Elastic has performed an investigation to identify any Elastic Products which may be impacted by this issue and we have concluded that no Elastic products use the versions of OpenSSL affected by these vulnerabilities. Therefore, Elastic Products are not affected by this issue.
