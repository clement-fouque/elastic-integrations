### ECE Improper Authorization (ESA-2024-18)

It was identified that under certain specific preconditions, an [API key](https://www.elastic.co/guide/en/cloud-enterprise/current/ece-restful-api-authentication.html#ece-api-keys) that was originally created with a specific privileges could be subsequently used to create new API keys that have elevated privileges.

### Affected Versions:

ECE versions after 3.0.0 and before 3.7.2

### Solutions and Mitigations:

Users should upgrade to version 3.7.2.

**Severity:** CVSSv3: 8.1(High) - [CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H](https://www.first.org/cvss/calculator/3.1#CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H)
