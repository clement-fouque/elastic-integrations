# Elasticsearch Improper Handling of Exceptional Conditions (ESA-2023-24)

It was identified that malformed scripts used in the script processor of an Ingest Pipeline could cause an Elasticsearch node to crash when calling the [Simulate Pipeline API](https://www.elastic.co/guide/en/elasticsearch/reference/current/simulate-pipeline-api.html).

## Affected Versions:

Elasticsearch versions on or after 7.0.0 and before 7.17.14

Elasticsearch versions on or after 8.0.0 and before 8.10.3

## Solutions and Mitigations:

The issue is resolved in versions 8.10.3 and 7.17.14.
